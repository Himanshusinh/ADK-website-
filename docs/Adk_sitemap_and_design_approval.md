## PART 1 — SITEMAP AUDIT

### 1. Current Website — Page Overview

The existing site (adkeng.com) currently has the following pages:

| Page | Current Content |
|---|---|
| Home | Hero banner, company overview, product highlights, milestones, industries served |
| About Us | Company intro, timeline, capabilities, industries served |
| Products | 8 categories with sub-model pages: Fiber Laser Cutting, CNC Plasma Cutting, CNC Press Brake, Fiber Laser Welding, PEB Machinery, Shearing Machine, Panel Bender, Spares & Consumables |
| Application | 19 industry tiles (image + label only, no individual pages) |
| Gallery | Photo gallery |
| News & Events | Listing page |
| Career | Static landing page |
| Clients | Client logos / list |
| Contact Us | Head office, factory, and branch details |

### 2. Recommended Final Page List

To improve search visibility and give visitors a clearer path to the right information, the recommended final structure is:

| Page | Change from Current Site |
|---|---|
| Home | Retained, with a clearer primary call-to-action |
| About Us | Retained, with added leadership, certification, and facility photos |
| Products | Retained structure; standardized template (specs, brochure download, enquiry) across all models |
| Applications / Industries | Expanded into individual pages per industry, rather than a single tile grid |
| Gallery | Organized into Machines / Installations / Videos |
| Clients & Case Studies | Combined with testimonials and written case studies |
| News & Events | Retained if actively updated |
| Career | Retained, with live openings if available |
| Contact Us | Retained, with map embeds and complete branch-wise details |
| Resources (New) | Blog, downloadable catalogues, and FAQ |

**Proposed Navigation**
1. Home
2. About Us
3. Products
4. Applications
5. Gallery
6. Clients & Case Studies
7. Resources (Blog / Catalogues / FAQ)
8. News & Events
9. Career
10. Contact Us

### 3. Page-Wise Content Breakdown

The following sections appear on each page of the redesigned site:

| Page | Sections / Content Blocks |
|---|---|
| Home | Hero banner with primary CTA; product category highlights; company stats; why choose ADK; featured industries; testimonials strip; enquiry CTA |
| About Us | Company introduction; timeline (2015–2026); leadership/team; infrastructure & facility photos; certifications; core capabilities |
| Products (hub) | Category grid (8 categories) with entry points to each product family |
| Product Category Page | Category overview; list of models within the category; comparison highlights; enquiry CTA |
| Product Model Page | Hero image; key specifications table; brochure/spec-sheet download; related applications; enquiry form |
| Applications (hub) | Grid of all industries served, each linking to its own page |
| Application Page | Industry overview; recommended ADK machine(s) for that industry; sample use case; related client photos |
| Gallery | Machine Gallery; Installation & Site Photos; Video Gallery |
| Clients & Case Studies | Client logos; written case studies with results; testimonials |
| Resources | Blog listing; downloadable catalogues/spec sheets; FAQ |
| News & Events | Chronological listing of trade fairs, launches, and company updates |
| Career | Company culture summary; open positions (if any); application form |
| Contact Us | Head office and factory address with map embed; branch-wise address and phone; enquiry form |
